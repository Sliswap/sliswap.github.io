# Transaction Details

On the Trade page, there is a section that combines basic information and transaction data, allowing you to quickly understand the token and its recent market trading activity.

1. **Transaction**

    - Select different time ranges
    - View the number of buy and sell transactions for the base token
    - View the trading volume of both transaction types for the base token
    <p align="center"><img src="/docs/images/transaction-info/media/image1.png" alt="" /></p>

2. **Coin Information**

    Displays details about the base token:
    - Token logo, name, and contract address
    - Market capitalization of the token on the Endless chain
    - Total supply of the token
    - Maximum supply of the token
    - All-time high (ATH) price in USD
    - All-time low (ATL) price in USD
    - Token decimals (precision)
